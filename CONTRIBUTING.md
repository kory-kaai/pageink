# Contributing to PageInk

Thanks for helping improve PageInk. Keep contributions focused on the PDF text-overlay workflow.

## Development

```bash
npm install
npm run dev
npm test
npm run build
```

## Pull requests

1. Fork and branch from `main`
2. Use [Conventional Commits](https://www.conventionalcommits.org/)
3. Run `npm test` and `npm run build` before opening a PR

## Scope

In scope: text placement UX, export quality, performance, accessibility, privacy guarantees.

Out of scope for this repo: full Acrobat replacement, server uploads, OCR (unless proposed as a separate mode).
